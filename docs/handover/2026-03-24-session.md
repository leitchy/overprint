## Architecture Notes

### DescRow List Pattern
The description box renderer now uses an explicit `DescRow[]` list built upfront. The same list is used for:
1. **Counting** — total rows for cell sizing algorithm
2. **Splitting** — header rows vs body rows for column distribution
3. **Rendering** — dispatch on `row.kind` in the render loop

This eliminated three classes of bugs where counts didn't match rendering.

### Course Parts (Dynamic Computation)
Parts are computed dynamically from `mapExchange`/`mapFlip` controls — never stored. `countCourseParts()`, `getPartBounds()`, `getPartControls()` in `course-parts.ts`. The exchange control belongs to BOTH adjacent parts (convention documented in function header).

### Konva Layer Blend Gotcha
`mixBlendMode: 'multiply'` on one Konva Layer canvas affects ALL subsequent sibling Layer canvases in the CSS stacking context. Must set `mixBlendMode: 'normal'` explicitly on layers that need opaque rendering. See `memory/feedback_konva_blend.md`.
